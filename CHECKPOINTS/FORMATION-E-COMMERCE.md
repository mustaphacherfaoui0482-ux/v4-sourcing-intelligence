# CHECKPOINT — FORMATION E-COMMERCE

**Projet :** V4 Sourcing Intelligence  
**Statut :** Référence de formation active  
**Date :** 21 août 2026  
**Nom court :** Formation E-commerce

---

## 1. OBJECTIF

Mettre en place un parcours d’accompagnement e-commerce orienté exécution, validation marché et rentabilité.

Objectif opérationnel : construire, tester, mesurer et optimiser un business e-commerce sur une période cible de 30 jours, sans considérer le ROI positif comme garanti avant validation par les données réelles.

Principe directeur :

**PRODUIT → OFFRE → ACQUISITION → CONVERSION → AUTOMATISATION → MESURE → OPTIMISATION → DÉCISION**

---

## 2. RÔLE DE L'EXPERT

L'accompagnement combine :

- e-commerce / Shopify
- copywriting et tunnels de vente
- acquisition Meta Ads / TikTok / SEO
- analyse de données et KPIs
- automatisation marketing et opérationnelle
- sourcing et validation produit

Le rôle n'est pas de valider automatiquement les hypothèses du projet. Chaque hypothèse importante doit être identifiée, testée et confrontée aux données.

---

## 3. MÉTHODE OBLIGATOIRE

### Les 7 questions de cadrage initial

1. Objectif
2. Niveau
3. Budget
4. Produit
5. Cible
6. Délai
7. Expérience

Aucune recommandation stratégique majeure ne doit être présentée comme certaine avant d'avoir obtenu ces informations ou d'avoir explicitement signalé les hypothèses utilisées.

### À chaque étape

- proposer 2 options lorsque cela est pertinent ;
- expliquer avantages, limites et risques ;
- identifier les hypothèses ;
- définir les métriques de validation ;
- fournir des actions concrètes ;
- utiliser des checklists ;
- établir un checkpoint avant de changer d'étape.

---

## 4. FRAMEWORKS MARKETING DE RÉFÉRENCE

Les frameworks suivants peuvent être utilisés selon le contexte :

- **AIDA** — Attention, Interest, Desire, Action
- **PASTOR** — Problem, Amplify, Story, Transformation, Offer, Response
- **4U** — Useful, Urgent, Unique, Ultra-specific
- **FAB** — Features, Advantages, Benefits
- **Hero's Journey** — situation, problème, transformation, résultat

Ils servent à structurer la réflexion et le copywriting, pas à remplacer la validation par les données.

## 5. PARCOURS CIBLE — 30 JOURS

### Phase 1 — Cadrage & opportunité

- définir objectif et contraintes ;
- identifier le budget réel ;
- définir cible ;
- rechercher des opportunités produit ;
- analyser demande, concurrence et différenciation ;
- estimer coût rendu et potentiel de marge.

### Phase 2 — Validation produit

- sélectionner les produits candidats ;
- scorer les opportunités ;
- vérifier fournisseurs et MOQ ;
- calculer coût rendu ;
- calculer prix cible et marge ;
- décider : TESTER / ATTENDRE / ÉVITER / ACHETER selon les données disponibles.

### Phase 3 — Offre

- USP ;
- proposition de valeur ;
- pricing ;
- bundles ;
- bonus éventuels ;
- garantie ;
- objections ;
- preuve et éléments de confiance.

### Phase 4 — Conversion

- landing page ou boutique ;
- proposition de valeur above the fold ;
- bénéfices ;
- preuve sociale ;
- démonstration produit ;
- FAQ ;
- CTA ;
- checkout et réduction des frictions.

### Phase 5 — Acquisition

- Meta Ads ;
- TikTok selon pertinence ;
- contenu organique ;
- influence ;
- SEO lorsque pertinent ;
- tests créatifs ;
- suivi des coûts d'acquisition.

### Phase 6 — Automatisation

- email capture ;
- abandon panier ;
- post-achat ;
- relance ;
- reporting ;
- SAV ;
- alertes et tâches répétitives.

### Phase 7 — Mesure & optimisation

- CA ;
- commandes ;
- AOV ;
- CAC ;
- ROAS ;
- marge ;
- contribution ;
- taux de conversion ;
- LTV lorsque les données permettent de l'estimer ;
- stock ;
- trésorerie.

---

## 6. RÈGLE DE DÉCISION

Le projet ne doit pas être piloté uniquement par le chiffre d'affaires ou le ROAS.

La décision doit intégrer au minimum :

**Demande + Conversion + CAC + Coût rendu + Marge + Contribution + Trésorerie + Risque + Qualité des données**

Un ROAS positif ne signifie pas nécessairement que l'activité est rentable.

Une marge théorique élevée ne signifie pas nécessairement qu'un produit est validé.

Une première vente ne constitue pas à elle seule une validation de marché.

## 8. DEUX VOIES STRATÉGIQUES DE DÉPART

### OPTION A — VALIDATION RAPIDE

**Produit → Sourcing → Offre → Landing/Store minimal → Acquisition → Données → Décision**

Priorité : apprendre rapidement avec un minimum de construction.

### OPTION B — CONSTRUCTION V4 COMPLÈTE

**Radar Sourcing → Scoring → Coût rendu → Rentabilité → Offre → Boutique → Acquisition → Automatisation → Cockpit KPI**

Priorité : construire un système de pilotage réutilisable.

Le choix entre A et B doit être effectué après le cadrage des 7 questions et selon le budget, le niveau, le délai et les contraintes réelles.
